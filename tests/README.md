# Тесты

## Сквозной тест клиента

    python3 tests/e2e.py

Поднимает сервер на порту 8899, заходит двумя вкладками настоящего браузера,
проходит путь «меню → лобби → выбор героя → матч → магазин → пауза →
отключение → возвращение» и проверяет каждый шаг.

Любая ошибка в консоли браузера роняет тест: молча сломанный клиент
хуже, чем упавший. Скриншоты каждого шага кладутся в `tests/shots/`.

Проверялось в Chromium (он есть в CI). Целевой браузер — Firefox 143;
клиент написан на стандартном ES2020 без специфичных для движка API.

## Проверка симуляции без клиента

    python3 tests/sim.py

Гоняет матч вхолостую и печатает темп: когда падают башни, как растут
уровни и золото. Полезно, чтобы ловить проблемы баланса без людей.
