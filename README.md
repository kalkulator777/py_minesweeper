# Офисная дота

MOBA в духе Dota 2 для локальной сети офиса. Три линии, лес, башни, трон,
экономика, герои, предметы — но вместо Роши легаси-код, а вместо башен
кулер, принтер и кофемашина.

Сделана под конкретное ограничение: **играть на перерывах составом,
который постоянно меняется**. Людей дёргают на созвоны, кто-то опаздывает,
кто-то уходит раньше. Игра это переживает.

---

## Запуск

```
pip install tornado
python3 play.py
```

Всё. Поднимется сервер, откроется браузер, в меню будет список матчей коллег
в вашей сети. Разбираться, кто «сервер», а кто «клиент», не нужно: запускают
все одинаково, а дальше либо создают свой матч, либо заходят в чужой.

Коллеге достаточно открыть адрес, который печатается при запуске
(например `192.168.1.42:8888`), но обычно и это не требуется — матчи
находят друг друга сами по UDP-броадкасту.

Требования: Python 3.11+, один пакет `tornado`, браузер Firefox 143+ или
любой современный. Интернет не нужен ни серверу, ни клиенту — все ресурсы
отдаются локально.

Полезные ключи:

```
python3 play.py --port 9000        # другой порт
python3 play.py --name "Матч Ани"  # как матч подпишется в списке
python3 play.py --no-announce      # не светиться в сети
python3 play.py --no-browser       # не открывать браузер
```

## Как играть

Управление дотовское, переучиваться не нужно.

| Действие | Клавиша |
|---|---|
| Идти / атаковать | правый клик |
| Способности | `Q` `W` `E` `R` |
| Повысить способность | `Shift` + клавиша, либо `+` на иконке |
| Предметы | `Z` `X` `C` `V` `B` `N` или `1`–`6` |
| Атака по земле | `A`, затем клик |
| Стоп / удержание | `S` / `H` |
| Камера на героя | `Пробел` |
| Магазин | `P` |
| Таблица счёта | `Tab` (удерживать) |
| Пауза | `F9` |
| Чат | `Enter` |
| Масштаб | колесо мыши |

Раскладка читается по коду клавиши, так что русская раскладка работает
так же, как английская.

## Что с нестабильным составом

Это главное, ради чего всё затевалось.

**Кто-то отключился** — матч встаёт на паузу сам, через 5 секунд после
разрыва. Мир замирает на том же тике: никто ничего не теряет. Все видят,
кого ждут.

**Он вернулся** — открывает ту же страницу и автоматически забирает своего
героя обратно. Дальше обратный отсчёт 3‑2‑1 и продолжаем. Узнаётся человек
по идентификатору в браузере, так что перезагрузка страницы или закрытая
вкладка ничего не ломают.

**Он не вернётся** — в окне паузы есть кнопка «Играть без него». Герой
переходит под управление бота, матч продолжается. Если человек всё-таки
вернётся, он заберёт героя у бота.

**Ручная пауза** — `F9`, в любой момент, любым игроком, без «банка паузы».
Все свои.

**Состав неравный** — экономика это учитывает. Доход команды растёт
медленнее её численности, а отстающая по числу людей команда получает
множитель к золоту и опыту. 1×3 остаётся тяжёлым, но не безнадёжным.
Обе крутилки выключаются одним флагом в `office_dota/game/data/tuning.py`,
если окажется, что гандикап раздражает больше, чем помогает.

## Герои

Каждый — узнаваемый аналог героя Dota 2. Если вы играли в доту,
переучиваться не придётся.

| Герой | Прототип | Роль |
|---|---|---|
| Сисадмин | Pudge | оффлейн-танк, инициатор |
| Сеньор | Juggernaut | керри поздней игры |
| Аналитик | Zeus | мидер-нюкер |
| Эйчар | Lion | хард-саппорт с контролем |
| Скрам-мастер | Dazzle | саппорт-лекарь |
| Безопасник | Bounty Hunter | убийца, ганкер |
| Бухгалтер | Leshrac | пушер |
| Джуниор | Phantom Lancer | иллюзии |

Предметов 36, тоже с прототипами: «VPN» — это Blink Dagger, «Отгул» — Black
King Bar, «Корпоративная карта» — Hand of Midas, «Годовая премия» —
Divine Rapier, которая так же выпадает при смерти.

Боевая модель повторяет дотовскую: та же формула брони, то же
мультипликативное сложение магического сопротивления, та же механика
скорости атаки. Размен считается так же, как вы привыкли.

## Как это устроено

```
play.py                  запуск одной командой
office_dota/
  launcher.py            выбор порта, печать адреса, открытие браузера
  server/
    app.py               Tornado: статика, WebSocket, цикл симуляции
    room.py              лобби, матч, игроки, пауза и реконнект
    ws.py                разбор сообщений
    discovery.py         обнаружение матчей в сети по UDP
  game/
    world.py             тик симуляции, приказы, бой, волны, экономика
    abilities.py         исполнитель эффектов — все примитивы из спецификации
    entities.py          юниты, герои, строения, снаряды
    combat.py            формулы урона Dota 2
    modifiers.py         баффы, дебаффы, контроль, щиты, ауры
    gamemap.py           карта: линии, лес, стены, поиск пути
    neutrals.py          лагеря, Легаси, руны
    bots.py              боты на замену ушедшим
    snapshot.py          что и кому отправляется
    data/                контент: герои, предметы, числа баланса
web/                     клиент: HTML, CSS, Canvas2D, ноль зависимостей
docs/
  DESIGN.md              принятые решения и их обоснования
  ABILITY_SPEC.md        контракт: как описываются способности и предметы
```

Ключевые решения и почему они такие — в [docs/DESIGN.md](docs/DESIGN.md).
Коротко:

- **Сервер авторитетен, клиентского предсказания нет.** В LAN пинг 1–3 мс,
  а управление в MOBA командное, а не непрерывное. Интерполяция снапшотов
  с буфером 100 мс ощущается точно так же, но стоит втрое меньше сложности.
- **Половина карты строится зеркалом другой.** Асимметрия баланса из-за
  опечатки в координатах невозможна по построению, и это проверяется тестом.
- **Способности описаны данными, а не кодом.** Новый герой — это запись
  в `data/heroes.py`, а не правка движка. Контракт в
  [docs/ABILITY_SPEC.md](docs/ABILITY_SPEC.md).
- **Тумана войны в виде сетки нет.** Видимость считается попарно — это
  на порядок дешевле и ровно то, что нужно снапшоту.

## Тесты

```
python3 tests/e2e.py     # настоящий браузер: меню, матч, пауза, реконнект
python3 tests/sim.py 12  # 12 минут матча ботов без клиента, для баланса
```

Сквозной тест падает от любой ошибки в консоли браузера: молча сломанный
клиент хуже, чем упавший.

## Что осознанно не сделано

- Курьера как юнита нет. Покупка доступна откуда угодно, доставка 12 секунд,
  на базе мгновенно.
- Нет высоты рельефа и промаха по возвышенности. Есть стены и комнаты.
- Нет рейтинга и матчмейкинга. Это офис, а не рейтинговая лестница.
- Герои Aghanim-апгрейдов не имеют, у ботинок нет переключения атрибутов,
  у BKB нет убывающей длительности. Список известных пробелов движка
  ведётся в `ENGINE_REQUESTS` внутри файлов `data/heroes.py` и `data/items.py`.
